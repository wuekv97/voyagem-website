Лаунчер в проекте VoyageM является ключевым объектом инфраструктуры для полноценной игры. 
Функционал лаунчера позволяет выбирать дополнительные доступные моды при которых вам не будет закрываться доступ на сервер. В список дополнительно доступных модов входят моды на внешнюю кастомизацию и модификации на оптимизацию.
Помимо вышеупомянутого, так же есть выбор темы лаунчера.
