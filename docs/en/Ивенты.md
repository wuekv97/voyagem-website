Throughout the season, events will run at varying frequencies. During active play hours (13:00 to 23:00) automated events will run without any involvement from the project's admins.
Alongside the automated events, admin-run events will also be held daily — the themes and tasks for these won't be announced in advance.
Automated events can help close the points gap to the leader when a player lower on the leaderboard wins. The base reward for winning an automated event is 100 points, but if first place wins, they get only 10 points. Each top spot down through 10th place earns −10 points depending on rank, so 10th place gets the full reward for winning an automated event.

## Seasonal events

You can choose to focus on winning seasonal events if you're confident in your victory — the payout of seasonal events outweighs the winnings from automated and daily events many times over.
Seasonal events run from the moment the season opens until it ends.
Winning a seasonal event can boost your counter in a big way.
The seasonal events themselves will be announced 3 days before the season runs.

### Automated events

**Schedule** — 6 events a day, 13:00–23:00 Kyiv time, spaced 1–3 hours apart; with rules for skipping when the server is empty and swapping in solo events.

**How points are awarded** — a standard placement scheme (100 / 50 / 25 … halved for each next place).

**Each event** — name, goal, how to win, and reward:

- 🎲 Bingo — collect 5 items of different rarities
- 🎯 Mob Hunt — kill the chosen mob with the chosen item (+ rules for night, the empty "anything goes" slot, and the Gravedigger's Hat)
- 💣 TNT Run — 3 rounds, with a separate rule for "3 different winners → 35 points each"
- 🎣 Skilled Angler — catch the required fish with a rod
- 🧠 Quiz — answer with numbers in chat
- 🏃 Parkour Sprint — race to the finish
- 🎰 Wheel of Fortune — pure luck, +100 to the winner
